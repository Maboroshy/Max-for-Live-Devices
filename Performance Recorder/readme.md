# Performance Recorder

This is a device you put on a main track to record an audio input and quickly save it to a file.  

![](https://github.com/Maboroshy/Max-for-Live-Devices/blob/main/Performance%20Recorder/Performance%20recorder%20gh.png?raw=true)

That's what makes it special:
- The device continuously records audio to a RAM buffer. You can set the length up to 2 hours. Looping recording. No record file clutter. Doesn't waste SSD space and lifespan.
- Save the record to a file with a press of the mappable button. Files named as the current date, time and bpm (if transport is running). 
- Clear the buffer with the mappable button, by saving a file, or just by starting to play after a silence. Your choice. Quickly restart recording takes and save the good ones. 
- Or don't clear at all and let it keep looping. Use the waveform view to select, preview and save any part of the recording. 
- The device trims the silence at the beginning and end of saved file. 

The device shows predicted RAM usage for the buffer (doubles for short time while saving). The record bit depth setting affects only a saved file. Max for Live internal buffer is always 32 bits.

Waveform for a large buffer can slow down Ableton Live UI while visible. Hide the waveform when not needed.
